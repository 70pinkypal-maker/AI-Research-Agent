# 🤖 AI Research Agent

An AI-powered research agent built using **Python, LangChain, Gemini, Tavily, WeatherStack and Streamlit**.

The agent understands user queries and uses external tools such as web search and weather APIs to provide useful and up-to-date information.

---

## 🚀 Features

- 🤖 AI-powered responses using Google Gemini
- 🔍 Web search using Tavily
- 🌤️ Current weather information using WeatherStack API
- 🔗 Tool integration using LangChain
- 🖥️ Interactive Streamlit web interface
- ☁️ Deployed on Streamlit Cloud

---

## 🛠️ Tech Stack

- Python
- LangChain
- Google Gemini
- Tavily API
- WeatherStack API
- Streamlit
- Git & GitHub
